# Least Common Multiple | Mínimo Múltiplo Comum

## English

A beginner-friendly C program that calculates the least common multiple (LCM) of two positive numbers using a function.

### Technologies

C

### How to run

Compile with GCC:

```bash
gcc least_common_multiple.c -o least_common_multiple
```

Run the program:

```bash
./least_common_multiple
```

### Example

For `n1 = 6` and `n2 = 8`, the program displays:

```text
seu mmc de 6 e 8 é 24
```

### What I learned

- How to create a function that calculates the LCM of two numbers.
- How to use a loop and the modulo operator to test common multiples.
- How to validate that the input numbers are greater than zero.
- How to separate the calculation from the user interaction in `main()`.

### Future improvements

- Implement a more efficient solution using the greatest common divisor.
- Add validation for invalid or non-numeric input.
- Allow the user to calculate multiple LCMs without restarting the program.
